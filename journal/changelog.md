# 하네스 변경 근거

이 하네스는 **감이 아니라 실제로 어긋난 기록**으로만 고친다 (헌법 §10).
원본 장부는 기본적으로 `~/.claude/harness/journal/drift-log.md`에 있고, 동기화가 필요하면
사용자가 지정한 프라이빗 저장소에 둔다. 이 파일은 그중 **공개해도 되는 부분** — 어떤 실패가 관측되어
어떤 규칙이 바뀌었는지 — 만 옮겨 적은 것이다.

규칙이 왜 지금 모습인지 궁금하다면 여기를 보면 된다.

| 날짜 | 유형 | 관측된 실패 | 하네스 변경 |
| --- | --- | --- | --- |
| 2026-08-11 | 실행 | `/kickoff` 이 생성한 프로젝트 `CLAUDE.md` 에 "다른 도구를 임의로 **제안**하지 않는다"가 들어가, 헌법 §2 제안 규칙("실행하지 말고 제안으로 남긴다")과 정면 충돌했다. 템플릿이 "실행 금지"와 "제안 금지"를 구분하지 않아 프로젝트에서 고쳐도 다음 `/kickoff` 때 재생산되는 구조였다 | `skills/kickoff/SKILL.md` 의 고정값 템플릿 문구를 "쓰지 않는다"로 바꾸고 제안 규칙을 명시 |
| 2026-08-11 | 품질 | 이탈 로그를 비공개로 돌리는 방법을 물으면서 선택지의 **결과를 다 적지 않았다** — `.gitignore` 로 제외하면 여러 컴퓨터 간 동기화가 끊긴다는 점을 빠뜨려, 사용자가 결정을 되돌려야 했다 (헌법 §4 "선택지와 각각의 결과를 함께 제시한다" 위반) | 장부를 별도 프라이빗 저장소(`journal/private/`)로 분리 — 비공개와 동기화를 동시에 만족시키는 구조로 변경 |
| 2026-08-12 | 실행 | 정본(`CLAUDE.md`)의 일부를 고치면서 나머지 등급 A 항목은 **"등급 A라 손대지 않았다"고 문서에 적고 그대로 커밋**했다. 그 결과 정본 한 파일 안에 서로 모순되는 서술이 남았고, 보고는 커밋 뒤에 이루어졌다 — **등급 A를 사실상 등급 B(사후 보고)로 강등**한 것이다. 한 세션에서 2회 반복됐고, 적대 리뷰가 두 번 다 지적했는데도 커밋됐다 | §2에 **"미승인 등급 A의 처리"** 절 신설 — 확정 직전 점검, 걸림 단위("이번 확정에 포함되는 파일"), 정본 자기모순 시 **파일에도 남기지 않음**, 보류의 유효 범위를 규정. §7에 **리뷰가 등급 A를 지적하면 커밋 전 사용자 승인** 불릿 추가 |
| 2026-08-13 | 실행 | 공개를 준비하면서 노출면을 **추적 파일과 트리로만** 보고 커밋 메시지 본문을 빠뜨렸다(2026-08-11 기록). 파일을 옮기거나 `.gitignore` 로 빼는 대책은 트리만 다루므로 메시지 경로가 그대로 남는다 — 대책이 노출면의 일부만 덮고 있었다 | 저장소를 **비공개 정본 + 공개 미러**로 재편. 공개 범위를 저장소 경계가 아니라 발행 시점의 **허용목록**으로 옮겼고(최상위에 새로 만든 파일의 기본값은 "공개 안 됨"), 공개 커밋 메시지는 정본에서 넘기지 않고 발행할 때 새로 쓴다 — 메시지 유출 경로 자체를 없앴다 |
