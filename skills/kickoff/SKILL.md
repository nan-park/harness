# kickoff — 프로젝트 진입 인터뷰

목적은 **등급 A 판정의 기준선을 만드는 것**이다.
"범위 밖 파일", "합의한 접근법", "해석이 갈리는 지점" 은 모두 이 인터뷰 산출물이 있어야 판정할 수 있다.
문서가 없으면 헌법 §2는 작동하지 않는다.

**빈 파일은 없는 것으로 본다.** 0바이트 `CLAUDE.md` 가 놓여 있어도 인터뷰 대상이다 —
파일이 존재한다는 사실이 아니라 판정 기준이 적혀 있는지가 조건이다.

## 0. 먼저 읽는다 — 묻기 전에

질문을 던지기 전에 저장소에서 **이미 알 수 있는 것을 먼저 파악한다.** 사용자에게 저장소만 봐도 아는 것을 묻지 않는다.

- `README.md`, 기존 문서, `package.json`·`CMakeLists.txt`·`pyproject.toml` 등 빌드 파일
- `git log --oneline -20`, 디렉터리 구조
- 요구사항 원본이 있으면 그것 (PDF·이슈·명세)

파악한 것은 인터뷰에서 **질문이 아니라 확인**으로 제시한다. ("README를 보니 X로 보입니다. 맞습니까?")

## 1. 인터뷰 — 7개 항목

한 번에 다 던지지 않는다. 선택지가 있는 것은 선택지와 **각각의 결과**를 함께 제시하고, 4개 이하씩 나눠 묻는다 (헌법 §4).

| # | 묻는 것 | 이것이 없으면 |
| --- | --- | --- |
| 1 | 목적 한 문장과 **성공 기준** | 모든 판단의 기준선이 없다 |
| 2 | **하지 말아야 할 것 (비목표)** | 등급 A ②(범위 밖)를 판정할 수 없다 |
| 3 | 언어·프레임워크·버전 등 **고정값** | 등급 A ③(의존성 추가)을 판정할 수 없다 |
| 4 | 산출물과 그 위치 (코드 구조, 문서 폴더) | 어디에 쓸지 매번 되묻게 된다 |
| 5 | 마감·일정 제약 | 범위를 잘라야 할 때 근거가 없다 |
| 6 | **이 프로젝트에서만 다르게 할 규칙** | 헌법이 안 맞는 프로젝트에서 마찰이 쌓인다 |
| 7 | 참고 자료 위치와 **이탈 기록 사용 여부** | 매 세션 같은 것을 다시 찾거나, 동의 없이 업무 내용을 기록하게 된다 |

2번이 가장 중요하다. 답이 잘 안 나오면 구체적으로 유도한다 — "이번 작업에서 손대지 말아야 할 파일/영역이 있습니까?", "하면 안 되는 것으로 미리 정해둘 것이 있습니까?"

6번은 헌법에서 `[조정 가능]` 표시된 항목만 대상이다. 안전 예외(§8)와 등급표(§2)의 골격은 프로젝트가 덮어쓸 수 없다.

## 2. 산출물 2개

### 프로젝트 `CLAUDE.md`

```
# <프로젝트명>

## 목적
<한 문장> / 성공 기준: <관측 가능한 형태로>

## 하지 않을 것 (비목표)
- <항목>

## 고정값
| 항목 | 값 | 비고 |
언어·버전·빌드·테스트·주요 라이브러리.
여기 적힌 것과 다른 도구를 **쓰지** 않는다. 추가·변경은 등급 A.
(제안까지 막지 않는다 — 헌법 §2 제안 규칙대로 보고 끝에 남긴다.)

## 산출물과 위치
| 무엇 | 어디에 |

## 일정
착수·마감·중간 기준점. 범위를 잘라야 할 때 무엇을 먼저 자를지.

## 이 프로젝트의 예외 규칙
헌법 대비 다르게 하는 것. 없으면 "없음"이라고 적는다.

## 참고 자료
| 자료 | 위치 | 무엇을 볼 때 |

## 이탈 기록
사용 / 사용 안 함. 기본값은 "사용 안 함"이다.
"사용"이면 재작업·방향 수정 시 로컬 harness 장부에 프로젝트명과 요약을 기록한다.
```

### `PROGRESS.md`

30줄 상한. 넘으면 오래된 것을 지운다. 새 세션이 이 파일만 읽고 이어받을 수 있어야 한다.

```
# 진행 상황  (갱신: YYYY-MM-DD)

## 현재 단계
## 직전 완료   ← 무엇을 어떻게 검증했는지 포함
## 지금 할 일  ← 최대 3개
## 열린 결정   ← 사용자 답을 기다리는 것
## 막힌 것     ← 없으면 "없음"
```

## 3. 승인

두 파일 초안을 **보여주고 승인받은 뒤에 쓴다.** 인터뷰 결과를 임의로 해석해 확정하지 않는다.

## 4. 이후

- 이 인터뷰 자체가 등급 A 판정의 계약이다. 작업 중 계약을 벗어나야 하면 그것이 곧 등급 A다
- 프로젝트가 진행되며 비목표·고정값이 바뀌면 프로젝트 CLAUDE.md를 갱신한다. 갱신도 등급 A다
